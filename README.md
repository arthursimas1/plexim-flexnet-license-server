# Dockerized Plexim PLECS FlexNet License Server

> Unofficial Docker container for the Plexim (PLECS) FlexNet Network License Manager.

This repository provides an automated Docker build for the **Plexim FlexNet License Manager**, allowing you to easily deploy and run a **PLECS network license server** (`lmgrd`) inside a lightweight Ubuntu container.

This containerized solution simplifies license management for PLECS simulation software, making it easy to host your network license on any Docker-compatible environment.

## 🚀 Quick Start: Docker Compose Deployment

A typical usage example involves mapping a single local license file (e.g., `plexim.lic`) to the container's `/var/flexlm` directory. You must also pass the MAC address and hostname that match your license file.

You can easily deploy the server using a `docker-compose.yml` file:

```yaml
version: '3.8'

services:
  plexim-license-server:
    image: ghcr.io/arthursimas1/plexim-flexnet-license-server:latest
    hostname: <license-hostname>
    container_name: plexim-license-server
    mac_address: <license-mac-address>
    ports:
    - "27000-27009:27000-27009"
    volumes:
    - ./plexim.lic:/var/flexlm/plexim.lic:ro
    restart: unless-stopped
```

## Logging

By default, Docker's built-in logging functionality will seamlessly collect the `stdout`/`stderr` streams generated by `lmgrd`. You can view them using:

```bash
docker logs plexim-license-server
```

If you prefer to keep a dedicated log file on your host machine, you can override the default container command to pass the `-l` option and add a volume mount in your `docker-compose.yml`:

```yaml
    volumes:
    - ./plexim.lic:/var/flexlm/plexim.lic:ro
    - ./plexim.log:/var/log/flexlm/plexim.log
    command: -c /var/flexlm/plexim.lic -l /var/log/flexlm/plexim.log
```

Using the `-l` flag will redirect the output away from stdout, causing `docker logs` to be empty.

## Troubleshooting

### Finding your LMHostID

When the container starts, the entrypoint automatically prints your `lmhostid` to the console before starting the server. You can view this by checking the container logs.

### Checking PLECS License Server Status

If you are unsure if the server is running correctly or if licenses are being issued properly, you can open an interactive bash shell inside the running container:

```bash
docker exec -it plexim-license-server /bin/bash
```

Once inside, you can run the `lmstat` utility:

```bash
lmutil lmstat -a -c /var/flexlm/plexim.lic
```

## Building a Custom Docker Image

This image is built in a two-stage process using `ubuntu:22.04`. It utilizes a build argument to fetch the installer, making it easy to build the image for newer releases of the FlexNet manager without changing the `Dockerfile`.

| Name | Required | Description |
| --- | --- | --- |
| `PLEXIM_FLEXNET_URL` | No | URL to the official Plexim FlexNet License Manager `.tar.gz` file for Linux. |

**Usage example:**

```bash
docker build \
  --build-arg PLEXIM_FLEXNET_URL="https://www.plexim.com/.../new_version.tar.gz" \
  -t plexim-flexnet-license-server \
  --network=host .
```
